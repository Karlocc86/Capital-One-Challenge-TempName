# Frontend — Predictor "¿Llego a fin de mes?"

Dashboard en Next.js 14 + Tailwind. Instrucciones completas (setup, variables de entorno, estructura) en el [README del repo](../README.md#frontend-nextjs-puerto-3000).

```bash
pnpm install
cp .env.local.example .env.local
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).
